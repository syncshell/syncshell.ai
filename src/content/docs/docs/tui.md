## The intended experience

See what is syncing, find folders that need attention, and use common controls
from the keyboard. The terminal interface is intended for local terminals, SSH
sessions, and machines without a desktop shell.

Like the other interfaces, it will control an existing Syncthing instance. It is
intended to install independently of the Omarchy plugin.

## Where it stands

The TUI is planned after the standalone Web UI release. Its exact feature set
and supported platforms will be documented when there is a usable build. There
is no release date or download yet.

For an interface you can use today, see the [Omarchy plugin](/docs/plugin/) and
[Web UI](/docs/web/). The [project overview](/docs/) explains the broader
direction.
