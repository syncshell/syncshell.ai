## The intended experience

A dedicated window for Syncthing, with desktop conveniences such as native
folder pickers, notifications, and secure credential handling. The application
is intended to work independently of any particular shell or plugin.

It will use your existing Syncthing instance. The desktop application should add
useful local workflows while keeping the same status and action meanings as the
shell, browser, and terminal interfaces.

## Where it stands

Desktop is a later step, after the terminal interface establishes shared
behavior. Supported operating systems and the first feature set have not been
committed to a release. There is no download or release date yet.

The [Web UI](/docs/web/) already offers folder and device management in your
browser. Read the [project overview](/docs/) for the planned family of
interfaces.
